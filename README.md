
# G10 Finanças

## Sobre o projeto

O G10 Finanças é um sistema web desenvolvido para auxiliar pequenos empreendedores, comerciantes e trabalhadores autônomos na organização e no controle de suas finanças.

O projeto busca simplificar o acompanhamento das movimentações financeiras, permitindo maior controle sobre receitas, despesas, pagamentos e recebimentos.

## Problema identificado

Pequenos empreendedores frequentemente enfrentam dificuldades para organizar suas movimentações financeiras e acompanhar a situação financeira de seus negócios.

O G10 Finanças propõe uma solução simples, acessível e organizada para essa necessidade.

## Objetivo do MVP

Desenvolver uma aplicação web responsiva que permita:

- Cadastrar receitas e despesas.
- Registrar pagamentos e recebimentos.
- Consultar o histórico de movimentações.
- Acompanhar informações financeiras.
- Gerar relatórios básicos.

## Tecnologias planejadas

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Git e GitHub

## Arquitetura

O sistema será desenvolvido utilizando arquitetura monolítica em camadas:

- Controller: recebe e processa as requisições.
- Service: concentra as regras de negócio.
- Repository: realiza o acesso aos dados.
- Model: representa as entidades do sistema.

## Escopo do MVP

A primeira versão prioriza as funcionalidades essenciais de controle financeiro.

Integrações bancárias, emissão de notas fiscais e controle de estoque não fazem parte do escopo inicial.
