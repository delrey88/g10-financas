# Backend - G10 Finanças

## Descrição

Este diretório contém a estrutura inicial do backend do sistema G10 Finanças.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- MySQL

## Organização da arquitetura

O backend seguirá uma arquitetura monolítica em camadas:

- controller: gerenciamento das requisições.
- service: regras de negócio.
- repository: acesso aos dados.
- model: entidades do sistema.
- config: configurações da aplicação.

## Funcionalidades previstas

- Cadastro de receitas.
- Cadastro de despesas.
- Consulta de movimentações financeiras.
- Acompanhamento de pagamentos e recebimentos.

## Objetivo

Preparar uma estrutura organizada, modular e de fácil manutenção para o desenvolvimento do MVP.
